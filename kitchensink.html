What is a kitchen-sink page?

A kitchen-sink page is a developer reference that exercises every notable HTML element and UI pattern in a single document, making it easy to verify styling and behavior at a glance.

Why use semantic HTML?

Semantic HTML improves accessibility for assistive technologies, aids search-engine indexing, and makes code easier to understand and maintain.
